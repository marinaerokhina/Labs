# Пятнашки — головоломка на JavaFX

[English README](README.md) · [Все лабораторные](../../)

Игра «Пятнашки» с полем **N × N**, а не только стандартным 4 × 4. Цель — собрать числа по порядку, оставив пустую ячейку справа внизу. Главная задача работы — отделить правила игры от JavaFX-интерфейса.

## Что реализовано

- Создание поля от **3 × 3** (по умолчанию — 4 × 4).
- Перемешивание с проверкой **разрешимости** полученного расположения.
- Перемещение плитки кликом только при соседстве с пустой ячейкой.
- Динамическая сетка `GridPane`, статус нового поля и сообщение «Собрано!» при победе.
- Проверка порядка плиток и вычисление числа инверсий для отличия решаемых комбинаций от нерешаемых.

## Архитектура и применённые подходы

**Слоистая архитектура.** `Board` в Domain хранит `int[][]` и реализует правила, не зная о кнопках и окнах. `GameService` в Application создаёт игру, запускает перемешивание и пробует ходы. `GameController` в Presentation отвечает только за события мыши, построение поля и отображение состояния.

**Value Object.** `Position` — неизменяемый `record(row, col)`. Его метод `isAdjacent()` вычисляет манхэттенское расстояние: для разрешённого хода оно должно равняться единице. Вместо повторения проверки в обработчике клика правило сосредоточено в одном месте.

**Интерфейс между слоями.** Контроллер обращается к `IGameService`, а не работает напрямую с массивом плиток.

**Алгоритм разрешимости.** Для нечётной ширины учитывается чётность числа инверсий; для чётной — дополнительно номер строки пустой клетки, считая снизу. `GameService` перемешивает комбинацию заново, пока проверка не пройдёт.

## Что получилось

Самостоятельная JavaFX-игра с изменяемым размером поля и изолированными игровыми правилами. Исходный код можно читать по слоям, а не искать логику перемещения среди обработчиков интерфейса.

## Известные ограничения и потенциальные проблемы

- Ввод размера ограничен снизу, **но не сверху**: чрезмерное N может создать огромную сетку и замедлить программу.
- Перемешивание проверяет разрешимость, но не сложность головоломки; может получиться уже собранное поле.
- Нет счётчика ходов, таймера, сохранения партии и автотестов правил. Визуальная работа JavaFX при обновлении портфолио отдельно не проверялась.

## Запуск

Нужны **JDK 21**, Maven и графический интерфейс. Из этой папки:

```bash
mvn javafx:run
```

Сборка проходит в [GitHub Actions](../../.github/workflows/maven-labs.yml). Исходный архив и отчёт находятся в [корне репозитория](../../).
