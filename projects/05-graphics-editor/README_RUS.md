# Graphics Editor — графический редактор с Undo/Redo

[English README](README.md) · [Все лабораторные](../../)

Итоговая семестровая работа: небольшой редактор геометрических фигур на **JavaFX Canvas**. Основной акцент — паттерн **Command**, позволяющий отменять и повторять операции, а также полиморфизм фигур.

## Возможности

- Создание прямоугольников, кругов и равнобедренных треугольников.
- Создание двойным кликом по холсту или кнопкой; выбор типа в `ComboBox`.
- Выделение, перетаскивание, изменение размера через маркеры, удаление.
- Изменение порядка наложения: **Bring to Front / Send to Back**.
- **Undo/Redo** с горячими клавишами Ctrl+Z / Ctrl+Y и удаление по Delete.
- Сетка с шагом 20 пикселей, история до **50 команд**.

## Как использованы паттерны и алгоритмы

**Command.** `Command` задаёт `execute()`, `undo()` и `getDescription()`. Отдельные классы хранят данные для создания, перемещения, изменения размеров, удаления и изменения порядка фигур. Например, `MoveShapeCommand` сохраняет старые и новые координаты, чтобы восстановить предыдущую позицию.

**Два стека истории.** `CommandManager` использует `ArrayDeque` для отмены и повтора. Новая операция сбрасывает стек повтора; Undo отменяет команду и переносит её в другой стек, Redo выполняет повторно. При превышении лимита удаляется самая старая команда.

**Полиморфизм.** Абстрактная `Shape` определяет `draw()`, `contains()`, `isInResizeArea()`, `copy()` и размеры. `Rectangle`, `Circle` и `Triangle` переопределяют геометрию и маркеры.

**Геометрия.** Для треугольника попадание точки проверяется через **барицентрические координаты**. `ShapeManager` ищет объект с конца списка — так выбирается верхняя фигура при перекрытии.

**Разделение обязанностей.** `ShapeManager` управляет коллекцией и выделением, `MainController` обрабатывает мышь и клавиатуру, а JavaFX Canvas рисует результат. Во время перетаскивания объект перемещается сразу, но команда истории создаётся **один раз при отпускании мыши**, а не после каждого пикселя.

## Результат

Графический редактор с несколькими типами фигур, управлением глубиной и обратимыми действиями — хороший пример применения паттерна Command к реальному пользовательскому интерфейсу.

## Известные ограничения и баги по анализу кода

- `MoveShapeCommand.getDescription()` и `DeleteShapeCommand.getDescription()` возвращают строку **«Rectangle»** независимо от типа фигуры. Сама операция универсальна, но её текстовое описание для круга и треугольника неверно.
- Нет сохранения документа на диск, загрузки и экспорта рисунка в PNG; команда New очищает данные в памяти.
- Размеры и цвета создаваемых фигур частично случайны. Сложную логику изменения размера разных фигур ещё стоит проверить граничными GUI-тестами.
- Maven собирает проект, но автоматических тестов реального взаимодействия мышью нет.

## Запуск

Нужны **JDK 21**, Maven и графический интерфейс:

```bash
mvn javafx:run
```

Компиляция подтверждена [GitHub Actions](../../.github/workflows/maven-labs.yml); исходный архив и отчёт доступны в [корне репозитория](../../).
